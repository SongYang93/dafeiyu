# 大肥鱼修仙 Demo 实现计划

一个**可在浏览器直接打开的 demo 页面** (`index.html`)，展示大肥鱼打坐修仙的核心体验。用户打开即可看到蓝肥鱼打坐、境界切换、念大爱仙尊诗句、摸鱼互动的完整流程。

## 三、技术方案

### 3.1 技术栈
- **纯 HTML + CSS + 原生 JS**（零构建，双击 index.html 可跑）
- **Live2D Cubism 3/4 Web SDK**（加载开源皮套实现打坐/摸鱼/突破动画）
- **无后端**：灵气/境界进度存在 localStorage

### 3.2 核心模块
```
index.html
├── 左：背景图（当前境界水墨背景）
├── 中：大肥鱼 Live2D（打坐姿势，可切换动作）
├── 右下：灵气面板（当前境界、灵气值、弹幕指令提示）
└── 底部：弹幕输入框（模拟互动触发）
```

### 3.5 互动触发（纯前端模拟弹幕）
| 操作 | 效果 |
|------|------|
| 点「打坐」按钮（默认） | Live2D 保持打坐姿势，灵气每秒 +1 |
| 点「摸鱼」按钮 / 输入「摸鱼」 | 切换摸鱼动作（眨眼、摇尾巴、偷笑），念🔥级搞笑诗 |
| 点「念诗」按钮 / 输入「念诗」 | 随机念 🔥🔥 级仙尊语录，语音合成播报 |
| 点「加油」按钮 / 输入「加油」 | 灵气 +30，触发运功特效 |
| 灵气满 | 自动触发突破：雷劫特效 → 换服饰/背景 → 念🔥🔥🔥级神级诗 |
